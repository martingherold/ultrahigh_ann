# Literature

Martin G. Herold, Danupon Nanongkai, Joachim Spoerhase, Nithin Varma, and
Zihang Wu. “Sublinear Data Structures for Nearest Neighbor in Ultra High
Dimensions.” 41st International Symposium on Computational Geometry
(SoCG 2025), LIPIcs 332, Article 56.
[doi:10.4230/LIPIcs.SoCG.2025.56](https://doi.org/10.4230/LIPIcs.SoCG.2025.56)
